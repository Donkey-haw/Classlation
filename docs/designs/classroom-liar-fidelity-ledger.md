## 의도적 차이

교사 시안은 설정 폼과 이미 진행 중인 팀 상태를 동시에 보여 주는 개념 보드다. 실제 앱은 아직 방이 없을 때는 설정에 집중하고, 방 생성 뒤에는 설정 폼을 QR·입장 현황으로 교체한다. 교사가 수업 중 실수로 주제어를 수정하거나 비밀 내용을 프로젝터에 남기는 일을 줄이기 위한 운영상 분리다.

학생 시안의 휴대폰 외형은 화면 구조를 보여 주기 위한 장식이므로 구현하지 않았다. 실제 모바일 브라우저의 안전 영역과 viewport를 사용한다.

## 문구 차이

| 시안 문구 | 구현 문구 | 이유 |
|---|---|---|
| 게임에 참가하기 | 방에 들어가기 | QR로 이미 게임이 특정된 상태에서 더 직접적인 행동 문구 사용 |
| 당신은 팀원입니다 | 당신은 팀원입니다 | 동일 |
| 말했어요 | 발언을 마쳤어요 | 완료 버튼이 실제 발언 내용을 기록하지 않는다는 점을 더 분명히 표현 |
| 질문을 마쳤어요 | 질문과 답변을 마쳤어요 | 질문자와 응답자가 모두 끝난 뒤 누르도록 명확화 |
| 비밀 투표하기 | 후보별 `선택` | 한 번 더 확인 버튼을 두지 않고 후보 선택이 곧 비밀 제출이 되도록 단순화 |
| 라이어 탈출 / 수사팀 성공 | 라이어 탈출 / 수사팀 성공 | 동일 |
