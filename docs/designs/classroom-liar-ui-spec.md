# 클래스 라이어 UI 구현 기준

## 기준 시안

- 교사 데스크톱: `classroom-liar-teacher-concept.png` (1488×1024)
- 학생 모바일 상태: `classroom-liar-student-concept.png` (1680×941 보드 안의 4개 모바일 화면)

## 시각 방향

- 배경: 순백색 `#ffffff`
- 기본 글자: 짙은 남색 `#071633`
- 보조 글자: `#5c6577`
- 주 강조색: 코발트 블루 `#0759e6`
- 선택 배경: 옅은 블루 `#eef5ff`
- 경계선: `#cfd5df`, 1px
- 성공 연결 상태: `#0a9f4f`
- 라이어 역할 강조: 코랄 `#e84f5f`
- 모서리: 입력 10px, 주요 버튼 8px, 진행 행 8px
- 그림자와 그라데이션은 사용하지 않는다.

## 글꼴

- `Pretendard`, `Noto Sans KR`, `Apple SD Gothic Neo`, 시스템 sans-serif 순서
- 데스크톱 제목 40~48px, 모바일 제목 30~36px
- 입력·버튼 18~22px, 본문 16~18px
- 버튼 글자는 명시적으로 700 굵기를 사용한다.

## 컨테이너

- 교사 화면: 단순 헤더 아래 2열. 왼쪽 64%, 오른쪽 36% 진행 레일.
- 학생 화면: 420px 이하의 단일 세로 열. 한 화면에는 한 가지 주요 행동만 둔다.
- 중첩 카드와 장식용 배지·아이콘·통계는 사용하지 않는다.

## 핵심 구성 요소

- `AppHeader`: 가제 텍스트와 연결 상태
- `TeacherSetup`: 분류·주제어·팀 크기·라운드 수
- `RoomPanel`: QR, 방 코드, 입장 현황, 시작 버튼
- `TeamProgressList`: 팀별 단계·완료 인원·경과 시간·건너뛰기
- `StudentJoin`: 방 코드·별명
- `SecretRole`: 일반 학생/라이어의 서로 다른 비밀 화면
- `TurnScreen`: 현재 발언자 또는 질문자/응답자
- `VoteScreen`: 자기 자신을 제외한 팀원 선택
- `FinalGuess`: 라이어의 단 한 번 입력
- `RevealScreen`: 역할·주제어·팀 결과

## 반응형 기준

- 데스크톱 기준 시안: 1440×1024
- 학생 모바일 확인: 390×844
- 교사 화면이 900px 미만이면 2열을 1열로 접고 진행 레일을 아래에 둔다.
- 필수 버튼 최소 높이 56px, 학생 주요 버튼은 64px 이상.

## 상호작용

- 발언·질문은 타이머 없이 현재 학생이 완료 버튼을 눌러야 다음으로 이동한다.
- 학생에게는 자신의 역할에 허용된 정보만 표시한다.
- 교사는 비밀 역할·투표 내용이 아니라 팀의 단계와 진행만 본다.
- `f` 키는 브라우저 전체 화면을 토글한다.
