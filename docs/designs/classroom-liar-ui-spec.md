# 클래스 라이어 UI 구현 기준

## 1. 핵심 원칙

학생끼리 말로 할 수 있는 과정은 화면 조작으로 옮기지 않는다. 화면은 다음 네 순간에만 적극적으로 사용한다.

1. 방 입장과 팀 확인
2. 비밀 역할·주제어 확인
3. 익명 투표
4. 라이어와 실제 주제어 공개

대면 대화 중에는 `기기를 내려놓기`가 가장 강한 메시지여야 한다. 투표 시작은 대화가 끝난 뒤 팀원 한 명이 사용하는 보조 행동이다.

## 2. 시각 방향

- 배경: 순백색 `#ffffff`, 학생 외곽 배경 `#f7f9fc`
- 기본 글자: 짙은 남색 `#071633`
- 보조 글자: `#5c6577`
- 주 강조색: 코발트 블루 `#0759e6`
- 선택 배경: 옅은 블루 `#eef5ff`
- 경계선: `#cfd5df`, 1px
- 연결 상태: 초록 `#0a9f4f`
- 라이어 역할: 코랄 `#e84f5f`
- 형태: 얇은 선, 작은 둥근 모서리, 그림자와 그라데이션 없음
- 색만으로 정보를 구분하지 않고 기호·문구를 함께 사용한다.

## 3. 학생 화면 규격

- 기준 viewport: 390×844, 최대 카드 폭 480px
- 한 화면에는 하나의 판단 또는 행동만 둔다.
- 주요 버튼 높이는 최소 54px, 투표 후보는 최소 58px로 한다.
- 안내문은 12px 이상, 대화 규칙은 13px 이상을 유지한다.
- 단계가 바뀌면 화면 맨 위로 복귀한다.
- 장식 애니메이션은 역할 공개처럼 의미 있는 순간에만 0.5초 이내로 사용하고 `prefers-reduced-motion`을 따른다.

## 4. 학생 단계

### 입장

- `클래스 라이어`, 방 코드, 별명, `입장하기`
- 입장 후에는 팀이 공개될 때까지 별도 조작 없이 기다린다.
- 마감된 방에서 자동 복귀 정보가 없으면 `기존 참가자로 재입장 요청`을 제공하고, 승인 전에는 팀·역할 정보를 보여주지 않는다.

### 팀 배정과 자리 이동

- 큰 팀 번호와 팀 고유 색·기호·별칭을 함께 보여준다.
- 같은 팀 학생의 별명과 자신의 위치를 표시한다.
- 누를 버튼을 두지 않는다.
- 비밀 역할과 주제어는 아직 표시하지 않는다.

### 역할 공개

- `나만 보는 비밀 카드`임을 먼저 알린다.
- 팀원은 주제어, 라이어는 분류만 본다.
- 역할 확인 뒤 `확인했어요` 한 번만 누른다.
- 화면을 다른 사람에게 보이지 말라는 안내를 12px 이상으로 표시한다.

### 대면 대화

- `이제 기기를 내려놓으세요`를 화면의 핵심 제목으로 둔다.
- 단서와 질문 규칙은 두 문장 안에서 안내한다.
- `팀 투표 시작`은 파란 채움 버튼이 아니라 외곽선 보조 버튼으로 둔다.
- 학생별 발언 완료, 질문 완료, 다음 차례 버튼을 두지 않는다.

### 비밀 투표

- 자기 자신을 제외한 팀원을 충분히 큰 선택 행으로 보여준다.
- 선택이 곧 익명 제출이며 다른 학생에게 선택 내용을 공개하지 않는다.
- 동률이면 다시 기기를 내려놓고 대화한 뒤 같은 형태의 결선 투표로 돌아온다.

### 라이어 추측과 결과

- 라이어는 주제어를 입력하지 않고 팀원에게 말로 추측한다.
- 중립 공개 화면에는 성공 체크를 사용하지 않고 `정답`·`정답 공개!`로 표시한다.
- 라이어와 실제 주제어를 우선 표시한다.
- 지목된 사람과 라이어가 같으면 같은 이름을 중복 표시하지 않는다.

## 5. 교사 화면 규격

- 설정 전에는 게임 설명과 설정 폼을 2열로 보여준다.
- 방 생성 뒤에는 QR·방 코드·참가자와 팀별 진행 상태에 집중한다.
- 입장을 마감하면 팀을 먼저 공개하고 자리 이동 완료 후 별도로 게임을 시작한다.
- 팀 준비 화면에서 팀 추가, 빈 팀 제거, 자동 다시 섞기, 학생별 팀 이동을 제공한다. 모든 팀이 3명 이상일 때만 시작 버튼을 활성화한다.
- 재입장 요청은 연결이 끊긴 기존 참가자 선택, 승인, 거절을 한 카드 안에서 처리한다.
- 라운드마다 새 팀을 선택한 방은 다음 라운드 전에 같은 팀 준비 화면으로 돌아온다.
- 교사는 비밀 역할·주제어·개별 투표 내용을 볼 수 없다.
- 멈춘 팀의 투표 또는 결선 투표를 대신 시작할 수 있다.
- `f` 키로 전체 화면을 전환한다.

## 6. 제외하는 인터페이스

- 자동 발언 순서와 발언 타이머
- 학생별 발언·질문 완료 추적
- 온라인 주제어 추측 입력창
- 개인 점수·누적 순위·득표 수 공개
- 대화 중 계속 움직이는 장식
- 팀 구분을 색상에만 의존하는 표현

## 7. 현재 검증 기준

- 교사 1440×1024와 학생 390×844에서 잘림·겹침이 없어야 한다.
- 교사 1명·학생 5명의 전체 라운드와 교사 1명·학생 10명의 재입장·팀 편집·라운드 재편성 E2E를 통과해야 한다.
- 브라우저 콘솔 오류가 없어야 한다.
- `render_game_to_text()`가 현재 화면과 같은 단계를 설명해야 한다.
- 실제 교실에서는 팀 이동 시간, 전원 발화, 투표 시작 이해도를 관찰한다.
