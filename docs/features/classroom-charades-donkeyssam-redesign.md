# 몸으로 말해요 — 동키샘 브랜드 첫 적용

## Why

현재 몸으로 말해요는 기능과 교실 TV 가독성을 우선해 흰 배경과 단순한 카드로 구현되어 있다. 학생에게는 지루하고 차갑게 보일 수 있으므로 동키샘의 첫 브랜드 검증 대상으로 삼는다. 밝은 봄 아침의 숲속 마을, 나침반, 재료감 있는 게임 UI를 적용하되 교사의 빠른 조작과 큰 글자 가독성은 유지한다.

## User flow

1. 교사는 숲속 마을의 게임판처럼 구성된 준비 화면에서 팀 이름, 점수, 제한 시간과 주제 수를 확인한다.
2. `두 팀 주제 뽑기`를 누르면 두 팀의 주제가 서로 다른 재료·색의 큰 게시판에 동시에 나타난다.
3. `동시에 시작`을 누르면 주제가 가려지고, 중앙 타이머와 팀별 정답·오답 기록 버튼이 또렷하게 보인다.
4. `주제 선택`에서는 추천 카테고리와 개별 주제를 교사용 밀도의 정돈된 숲속 장부 화면에서 편집한다.

## Completion criteria

- 준비, 주제 공개, 진행, 주제 선택 네 화면이 하나의 동키샘 숲속 마을 디자인으로 보인다.
- 기존 화면의 모든 문구, 조작, 팀별 점수, 제한 시간, 남은 주제, 기록 기능이 유지된다.
- 학생이 보는 주제와 타이머는 1440×1000 교실 TV에서 멀리서도 읽을 수 있다.
- 교사용 설정 버튼은 장식보다 빠른 구분과 조작을 우선한다.
- 주요 버튼과 카드는 나무, 종이, 천, 밧줄 같은 재료감을 직접 드러낸다.
- 동키샘 인물 캐릭터는 등장하지 않으며 나침반, 지도, 이정표, 발자국으로 안내자의 존재를 표현한다.
- 밝은 게임 효과음은 유지하되 기본 음소거 동작은 변경하지 않는다.
- 기존 단위 테스트와 전체 흐름 E2E가 통과하고 브라우저 콘솔 오류가 없다.

## Not included

- 게임 규칙, 점수 계산, 주제 데이터 변경
- 학생 기기 연결이나 온라인 방 기능
- Classlation의 다른 게임 동시 리디자인
- 동키샘 전체 브랜드 자산의 최종 확정
- 메이플스토리 캐릭터, UI, 그래픽 또는 상표의 복제

## Data and privacy

변경 없음. 현재처럼 교사 브라우저 메모리만 사용하며 외부 전송과 영구 저장을 추가하지 않는다.

## Button asset set

웹의 실제 한글과 클릭 동작은 코드에 남기고, 글자 없는 투명 PNG 틀을 배경으로 사용한다. 같은 파일을 Canva와 PPT에서도 불러와 위에 글자를 올릴 수 있다.

- `button-primary.png`: 초록 목재와 금색 테두리. 시작·확정·정답 행동
- `button-secondary.png`: 밝은 종이와 목재 테두리. 다시 뽑기·취소·보조 행동
- `button-danger.png`: 붉은 천과 짙은 목재 테두리. 초기화·오답 행동
- `button-toolbar.png`: 흰 목재와 민트색 테두리. 상단 설정·조용한 행동
- `button-round.png`: 흰 목재와 금색 원형 테두리. 점수 조절·닫기

마우스 올림·누름·비활성 상태는 별도 이미지를 늘리지 않고 밝기, 이동, 투명도 변화로 처리한다. 주제 선택 카드 전체를 이미지화하면 정보 밀도가 과도해지므로 실제 행동 버튼과 카테고리 탭에만 적용한다.

## Verification

- 승인 시안을 기준으로 독자적인 숲속 마을 배경과 나침반 PNG를 직접 제작해 적용했다.
- 1440×1000 화면에서 준비·주제 공개·진행·주제 선택 네 상태를 직접 비교했다. 세로·가로 넘침이 없고 제시어와 타이머를 큰 글자로 유지했다.
- 타입 검사, 단위 테스트 5개, 프로덕션 빌드와 전체 흐름 E2E를 통과했다.
- 팀 이름 표지의 배경색 누락을 실제 화면에서 발견해 수정했고, 수정 후 청·홍색 적용과 제시어 글자 넘침이 없음을 다시 확인했다.
- 투명 PNG 버튼 5종을 직접 제작해 주요 행동, 상단 도구, 정답·오답, 점수 조절, 모달 닫기와 카테고리 탭에 적용했다.
- 브라우저 콘솔 오류는 0건이다.
