# 돋보기 추리왕 이관 명세

## 목적

교사가 준비한 사진을 교실 TV에 부분 확대해 보여 주고 학생들이 대면으로 정답을 추리하는 게임이다.

## 구현 흐름

1. 교사가 사진과 정답을 한 문제 이상 등록한다.
2. 문제를 추가·삭제·재정렬하고 확대 범위를 고른다.
3. 게임 화면에서 서로 다른 사진 부분을 원하는 만큼 보여 준다.
4. 필요하면 초성 힌트를 켠다.
5. 정답 사진과 단어를 공개하고 다음 문제로 이동한다.
6. 마지막 문제 뒤 완료 화면을 보여 준다.

## 운영·데이터 원칙

- 교사 브라우저와 교실 TV만 사용한다.
- 사진은 브라우저 메모리에만 보관하고 서버로 업로드하지 않는다.
- 외부 CDN, 원격 이미지, 분석 도구를 호출하지 않는다.
- 새로고침하면 준비한 사진이 사라지는 것은 현재 의도된 제한이다.

## 이관하며 보완한 점

- 이미지 형식·12MB 크기·브라우저 디코딩을 검사한다.
- 삭제하거나 교체한 사진의 임시 URL을 해제한다.
- 다음 부분 확대가 직전 위치와 지나치게 겹치지 않도록 재추첨한다.
- 전체 화면 단축키 `F`와 자동 검증용 상태 출력을 제공한다.

## 이번 범위에서 제외

- Classlation 공통 브랜드·디자인 에셋 적용
- 문제 세트 저장·불러오기
- 학생 기기 접속과 네트워크 동기화
