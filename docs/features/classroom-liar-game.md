# 클래스 라이어 — 첫 게임 설계

> `클래스 라이어`는 가제다. 기존 상업 게임의 콘텐츠나 표현을 복제하지 않고, 교실에서 전원이 말하도록 규칙을 새로 설계한다.

## 1. 왜 이 게임인가

교사는 수업 직전에도 주제어만 바꿔 바로 게임을 열 수 있어야 한다. 학생은 휴대폰을 계속 보는 대신, 서로 설명하고 질문하고 경청해야 한다.

라이어 게임은 교사가 논리 퍼즐을 만들 필요 없이 `분류명 + 주제어 목록`만 입력하면 된다. 앱은 팀 편성, 비밀 역할 배정, 주제어 배포, 익명 투표와 결과 공개만 맡고 발언과 질문은 학생들이 직접 운영한다.

## 2. 한 문장 설명

4~6명이 한 팀이 되어 같은 주제어를 설명하고 질문하되, 주제어를 모르는 라이어 한 명은 대화에서 얻은 정보로 정체를 숨기고 마지막에 주제어까지 추리한다.

## 3. 설계 원칙

1. **대면 우선:** 학생끼리 말로 자연스럽게 할 수 있는 과정은 앱의 클릭 절차로 옮기지 않는다.
2. **간단한 준비:** 교사는 분류명과 주제어만 입력한다. 단서·정답 조건을 만들지 않는다.
3. **디지털 최소화:** 앱은 팀 편성, 비밀 정보 전달, 익명 투표, 자동 집계처럼 디지털이 유리한 일만 담당한다.
4. **탈락 없음:** 지목된 학생도 라운드 끝까지 참여하며 다음 라운드에 바로 복귀한다.
5. **역할 공정성:** 같은 학생이 반복해서 라이어가 되지 않도록 세션 안에서 역할을 순환한다.
6. **공개 망신 최소화:** 개인 누적 순위와 학급 전체 화면의 개인별 득표 공개를 하지 않는다.
7. **물리적 준비 먼저:** 팀 배정과 자리 이동을 비밀 역할 공개 전에 끝낸다.
8. **전원 발화는 규칙으로:** 모든 학생이 단서 한 번과 질문 한 번을 하도록 안내하되 개인별 완료 클릭으로 추적하지 않는다.

## 4. 대상과 기본값

- 학급 인원: 4~32명
- 팀 크기: 4~6명, 기본 5명. 전체가 7명일 때만 한 팀 7명 허용
- 라이어: 팀마다 1명
- 권장 라운드: 3회
- 예상 시간: 팀의 대화 속도에 따라 달라지며 첫 규칙 테스트에서 측정
- 기기: 학생 1인 1기기, 교사 MacBook 1대
- 통신: 같은 Wi-Fi의 로컬 웹 접속

## 5. 교사의 준비

### 빠른 입력

교사는 다음 두 항목만 필수로 입력한다.

```text
분류: 과학 개념

광합성
증발
생태계
마찰력
```

- 첫 줄의 분류는 라이어를 포함한 전원에게 보인다.
- 아래 주제어는 한 줄에 하나씩 입력한다.
- 각 팀·라운드의 주제어는 입력 목록에서 자동 배정한다.
- 같은 팀이 같은 세션에서 동일한 주제어를 다시 받지 않게 한다.
- 설명은 선택 사항이며 입력하면 결과 공개 때 전원에게 보여준다.

### 준비 시간 목표

- 새 주제어 3개로 방을 만드는 데 60초 이내
- JSON이나 파일 편집 없이 교사 화면에서 붙여넣기
- 빈 줄은 자동 제거하고 중복 주제어는 시작 전에 경고
- 사용할 팀 수보다 주제어가 적어도 반복 배정으로 시작 가능

## 6. 교사 흐름

1. `클래스 라이어` 선택
2. 분류명과 주제어 목록 입력
3. 팀 크기와 라운드 수 확인
4. 방 생성 후 QR과 방 코드 제시
5. 학생 입장을 마감하고 팀 자동 편성
6. 학생 화면과 교사 화면에 팀 번호·팀원 공개
7. 학생들이 팀별로 이동한 것을 눈으로 확인
8. 전체 게임 시작 후 비밀 역할·주제어 공개
9. 학생들은 기기를 내려놓고 단서·질문을 대면으로 진행
10. 팀이 준비되면 한 명 또는 교사가 비밀 투표 시작
11. 모든 팀이 끝나면 다음 라운드 시작
12. 마지막 라운드 후 세션 종료

## 7. 학생 흐름

### 준비 단계 — 공개 팀 배정

- 교사가 입장을 마감하면 앱이 팀을 편성한다.
- 학생 화면에는 큰 팀 번호와 같은 팀원의 별명을 보여준다.
- 아직 라이어나 주제어는 배정·공개하지 않는다.
- 학생은 별도 준비 버튼을 누르지 않고 같은 팀끼리 모여 앉는다.
- 교사가 실제 자리 이동을 확인한 뒤 게임을 시작한다.

### 0단계 — 비밀 확인

- 일반 학생: `분류 + 주제어`
- 라이어: `분류 + 라이어 역할`, 주제어는 보이지 않음
- 내용을 확인한 뒤 `확인했어요`를 누른다.
- 팀원 전원이 확인하면 대면 대화 안내 화면으로 넘어간다.

### 1단계 — 대면 대화

- 학생은 기기를 내려놓는다.
- 팀 안에서 순서를 정해 모든 학생이 주제어를 직접 말하지 않고 단서 한 번을 말한다.
- 이어서 모든 학생이 질문 한 번과 답변 한 번에 참여한다.
- 앱은 발언 순서, 질문 상대, 개인별 완료 여부를 추적하지 않는다.
- 대화를 모두 마치면 팀원 중 한 명이 `팀 투표 시작`을 한 번 누른다. 필요하면 교사가 해당 팀의 투표를 시작할 수 있다.

금지하는 힌트는 최소화한다.

- 주제어 자체 또는 글자 일부 말하기
- 첫 글자, 글자 수, 운율만 알려주기
- 다른 언어로 그대로 번역하기

### 2단계 — 비밀 투표

- 각 학생이 라이어라고 생각하는 팀원 한 명에게 비밀 투표한다.
- 자기 자신에게는 투표할 수 없다.
- 단독 최다 득표자가 나오면 그 학생을 지목한다.
- 동률이면 기기를 내려놓고 추가로 대화한 뒤 팀원 중 한 명이 결선 투표를 시작한다.
- 재투표도 동률이면 라이어가 잡히지 않은 것으로 처리한다.

### 3단계 — 라이어의 마지막 추리

- 지목된 학생이 실제 라이어가 아니라면 라이어가 즉시 승리한다.
- 실제 라이어가 지목되면 라이어는 주제어를 말로 한 번 추측한다.
- 라이어가 `정답 공개`를 누르면 실제 주제어를 보여주며, 팀은 말한 추측과 비교해 결과를 확인한다.

### 4단계 — 공개

- 팀 화면에 라이어와 주제어를 공개한다.
- 선택 설명이 있으면 함께 보여준다.
- 잘못된 학생을 지목했거나 재투표도 동률이면 `라이어 탈출`을 표시한다.
- 실제 라이어를 지목한 경우 앱은 말로 한 추측을 자동 판정하지 않고 `정답을 확인하세요`를 표시한다. 학생들은 공개된 주제어와 방금 들은 추측을 직접 비교한다.

## 8. 진행 방식

팀은 같은 시각에 시작하지만 각 팀 안에서는 자기 속도로 대화와 투표를 진행한다. 교사 화면에는 비밀 내용 대신 다음 상태만 보인다.

```text
1팀  대면 대화 중
2팀  비밀 투표  4/5명 완료
3팀  라이어 최종 추리
```

이 방식은 한 팀의 느린 진행이 학급 전체를 멈추는 일을 줄인다. 앱은 대화 중 개인의 순서나 시간을 통제하지 않는다. 팀원이 연결을 잃어도 대면 대화는 계속할 수 있으며, 재접속하면 같은 팀·역할·주제어로 돌아온다. 교사는 대화가 끝난 팀의 투표를 대신 시작할 수 있다.

## 9. 점수와 역할

첫 MVP에는 개인 점수와 전체 순위를 넣지 않는다.

- 라운드 결과는 자동 판정할 수 있는 경우만 `라이어 탈출`로 표시하고, 구두 추측은 정답 공개 후 팀이 직접 확인
- 한 세션 안에서 가능한 한 모든 학생이 한 번씩 라이어를 맡기 전에는 같은 학생에게 라이어를 다시 배정하지 않음
- 팀은 세션 중 유지하고, 직전 라운드의 라이어는 다음 라운드 후보에서 우선 제외

게임의 첫 성공 기준은 승률이 아니라 `모든 학생이 단서 1회 + 질문 1회 이상 발화했는가`다.

## 10. 콘텐츠 사용 예

| 수업 목적 | 분류 | 주제어 예시 |
|---|---|---|
| 아이스브레이킹 | 학교생활 | 급식, 운동장, 방학, 수행평가 |
| 과학 복습 | 생명과학 | 광합성, 세포, 생태계, 유전 |
| 역사 복습 | 조선 인물 | 세종대왕, 이순신, 신사임당, 정약용 |
| 국어 | 문학 용어 | 비유, 역설, 복선, 시점 |
| 영어 | 장소 | airport, library, hospital, museum |

추상적이거나 서로 너무 비슷한 주제어는 라이어에게 지나치게 어렵거나 일반 학생의 힌트를 모호하게 만들 수 있다. 앱은 이를 의미적으로 판정하지 않고, 시작 전 미리보기에서 교사가 목록을 확인하게 한다.

## 11. 교실 위험과 대응

| 위험 | 설계 대응 |
|---|---|
| 말 잘하는 학생이 토론 독점 | `모두 단서 1회·질문 1회` 규칙을 시작 화면과 교사 안내로 제시하고 실제 참여는 교사가 관찰 |
| 친분이나 인기 기반 투표 | 짧은 구조화 대화 후 비밀 투표, 개인 누적 득표 비공개 |
| 같은 학생이 계속 라이어 | 세션 내 역할 순환 |
| 라이어가 아무것도 배우지 못함 | 공통 분류 제공, 모든 단서를 경청한 뒤 주제어 최종 추리 |
| 언어 수준이 낮아 침묵 | 제한 시간 없이 설명·질문 방향 카드 제공, 필요하면 교사가 직접 안내 |
| 지목된 학생이 소외됨 | 탈락 없이 즉시 공개하고 다음 라운드 참여 |
| 옆 팀의 주제어를 엿들음 | 팀·라운드별 주제어 자동 분산, 필요 시 교사가 팀 간 간격 조정 |

## 12. 완료 기준

- 교사는 분류 하나와 주제어 세 개를 붙여넣어 60초 안에 게임 방을 만들 수 있다.
- 4~32명을 4~6명 팀으로 자동 편성하고 각 팀에 정확히 한 명의 라이어를 배정한다.
- 일반 학생에게만 주제어가 전달되고 라이어와 다른 팀에는 노출되지 않는다.
- 교사가 팀 배정을 먼저 실행하면 학생에게 팀 번호와 팀원만 공개되고 비밀 역할은 보이지 않는다.
- 팀 배정 후 새 학생 입장을 잠그고, 교사가 게임 시작을 눌러야 비밀 역할과 주제어를 공개한다.
- 대면 대화 단계에는 학생별 발언·질문 완료 버튼과 자동 진행이 없다.
- 팀원 한 명 또는 교사가 투표를 시작하면 해당 팀 전체가 비밀 투표 화면으로 이동한다.
- 비밀 투표, 동률 재투표, 라이어 최종 추리, 결과 공개가 규칙대로 완료된다.
- 새로고침하거나 잠시 연결이 끊긴 학생이 같은 팀·역할·주제어·진행 단계로 복귀한다.
- 교사는 멈춘 팀의 현재 단계를 보고 해당 팀의 투표 또는 결선 투표를 대신 시작할 수 있다.
- 세션 종료 시 별명, 역할, 투표 기록을 서버 메모리에서 삭제한다.
- 실제 4~6명 시험에서 전원이 한 라운드에 두 번 이상 말했는지 관찰 기록을 남긴다.

## 13. 첫 MVP에 포함하지 않음

- AI 주제어·힌트 자동 생성
- 서로 다른 단어를 받는 언더커버 역할
- 라이어 두 명 또는 특수 역할
- 음성 녹음, 음성 채팅, 자동 발언 판정
- 학생 발언 카운트다운과 자동 차례 넘김
- 학생별 발언·질문 순서 배정과 완료 클릭
- 욕설·부적절한 주제어 자동 판정
- 개인 누적 점수, 학급 순위, 영구 전적
- 계정, 클라우드 저장, 교사 간 콘텐츠 공유
- 공개 배포와 설치 패키지

## 14. 데이터와 개인정보

- 서버 메모리: 방 코드, 임시 별명, 팀, 역할, 주제어, 현재 단계, 투표
- 학생 기기: 재접속용 임시 키
- 외부 전송: 없음
- 음성 수집·저장: 없음
- 세션 종료 시: 참가자와 투표 데이터 삭제

교사가 입력한 주제어를 다음 수업에도 저장하는 기능은 첫 MVP 이후 별도로 결정한다.

## 15. 검증 상태

- 구현: `games/classroom-liar/`에 독립 React·Node·Socket.IO 앱으로 수직 슬라이스를 구현함
- 첫 현장 관찰: 학생들이 패드로 발언·질문 절차를 누르는 것을 번거로워하고 직접 말로 진행하는 방식을 선호함
- 첫 현장 관찰: 게임 시작과 동시에 팀을 확인하고 이동하면 역할 확인과 자리 이동이 겹쳐 번거로움
- 개정 구현 완료: 공개 팀 배정·자리 이동 단계를 게임 시작 전에 분리하고, 학생별 발언·질문 클릭을 대면 대화로 교체
- 자동 검증: 타입 검사, 프로덕션 빌드, 단위·통합 테스트 15개, 교사 1명·학생 5명의 전체 브라우저 흐름을 통과했으며 콘솔 오류는 0건
- 레퍼런스 확인: 국내 온라인 라이어 게임, Spyfall 계열, Jackbox `Fakin' It`, 교실 말하기 활동 사례를 비교함
- 미검증: 개정 흐름에서 팀 이동 시간, 대면 대화의 전원 참여, 한 명만 누르는 투표 시작 방식의 이해도
- 다음 검증: 실제 학생으로 두 번째 파일럿을 진행해 팀 이동 시간, 전원 발화, 한 명만 누르는 투표 시작 방식의 이해도를 관찰

## 16. 참고한 구조

- [올웨이즈 라이어 게임](https://alwayscorp.co.kr/games/liar-game): 방 입장, 비밀 역할·단어, 투표, 재접속의 온라인 운영 사례
- [Jackbox Fakin' It](https://www.jackboxgames.com/games/the-jackbox-party-pack-3/fakin-it): 한 명만 지시를 모른 채 행동하고, 질문과 여러 라운드로 가짜를 찾는 구조
- [Spyfall 규칙](https://www.cryptozoic.com/sites/default/files/icme/u30695/spy_rules_eng_0.pdf): 질문·응답, 스파이 지목, 스파이의 장소 추측 구조
- [Cambridge English Classroom Warmers](https://www.cambridgeenglish.org/my/Images/594825-warmer-activity-booklet.pdf): 소그룹 말하기 순서, 질문·답변, 어휘 복습 활동 설계 참고

참고 게임의 고유 문구, 카드, 시각 자산과 콘텐츠는 사용하지 않는다.
