# 몸으로 말해요 이관 명세

## 목적

교사가 메인 TV 한 화면을 조작하고 두 팀이 각자의 서로 다른 주제로 동시에 몸으로 표현하는 게임이다.

## 의도된 정보 공개

준비 단계에서 1팀과 2팀의 주제·힌트를 같은 화면에 동시에 공개한다. 상대 팀의 정답을 알아도 괜찮다. 두 팀은 각자 다른 주제를 동시에 표현하고 맞힌다. 시작 버튼을 누르면 두 주제를 함께 가린다.

## 구현 흐름

1. 추천 카테고리에서 전체 또는 개별 주제를 고른다.
2. 필요한 경우 직접 만든 카테고리 이름과 주제 목록을 더한다.
3. 팀 이름과 30·60·90초 또는 제한 없음을 정한다.
4. 두 팀의 주제를 한 번에 뽑아 함께 확인한다.
5. 필요하면 다시 뽑는다. 버린 주제는 목록으로 돌아간다.
6. 동시에 시작하고 공통 타이머를 사용한다.
7. 교사가 팀별 정답·오답을 기록한다.
8. 두 팀 기록이 끝나면 다음 라운드로 이동한다.

## 주제 선택

- 추천 카테고리: 직업 30개, 동물 14개, 스포츠 14개, 일상 동작 14개, 감정·상황 14개
- 여러 추천 카테고리를 섞어서 선택할 수 있다.
- 한 카테고리 전체를 선택·해제하거나 개별 주제를 선택·해제할 수 있다.
- `직접 입력`에서 카테고리 이름과 `주제 | 이모지 | 힌트` 목록을 추가할 수 있다.
- 같은 단어가 추천 목록과 직접 입력에 함께 있으면 한 번만 사용한다.
- 선택한 주제는 두 개 이상이어야 하며, 새 목록 적용 시 점수와 진행 기록을 초기화한다.

## 운영·데이터 원칙

- 교사 브라우저와 교실 TV만 사용한다.
- 학생 기기, 방 코드, 비밀 전송, 재접속은 사용하지 않는다.
- 기본값으로 직업 30개를 선택해 두고, 총 86개의 추천 주제를 제공한다.
- 교사는 추천 주제를 고르거나 `주제 | 이모지 | 힌트` 형식으로 직접 추가할 수 있다.
- 데이터는 브라우저 메모리에만 있으며 새로고침하면 초기화된다.

## 이관하며 보완한 점

- 다시 뽑을 때 기존 두 주제가 소모되지 않는다.
- 바꾼 팀 이름을 모든 화면과 이후 기록에 반영한다.
- 시간 종료를 명시적으로 표시하며 음수가 되지 않는다.
- 동시 진행 규칙과 맞지 않는 `진행 팀` 강조를 제거했다.
- 점수 수동 보정과 진행 기록을 유지한다.

## 이번 범위에서 제외

- Classlation 공통 브랜드·디자인 에셋 적용
- 여러 기기 동기화
- 주제 목록의 영구 저장
