# 돋보기 추리왕

교사가 사진과 정답을 준비하고, 교실 TV에서 사진의 일부를 차례로 보여 주는 독립형 Classlation 게임이다.

```bash
pnpm install
pnpm build
pnpm start
```

`http://localhost:4173`을 연다. 학생 기기 접속은 사용하지 않는다. 업로드한 사진은 브라우저 메모리에만 머물며 서버로 전송되지 않는다.

문제 준비 화면에 사진을 여러 장 끌어다 놓거나 한 번에 선택하면 사진별 문제가 자동으로 만들어진다. 정답은 마지막 확장자를 뺀 파일명으로 먼저 채워지며 게임 시작 전에 자유롭게 수정할 수 있다.
